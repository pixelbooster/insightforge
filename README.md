```
┌─────────────────────────────────────────────────────────────┐
│              NOTEBOOK (Steps 1–7a)                          │
│                                                             │
│  Step 1: pandas EDA + statistical analysis                  │
│  Step 2: LangChain Documents + RecursiveCharacterTextSplitter│
│  Step 3: LLMChain + PromptTemplate + InsightRetriever       │
│  Step 4: SequentialChain (summary → recommendations)        │
│  Step 5: FAISS vector store + RetrievalQA chain             │
│  Step 6: ConversationalRetrievalChain + ConversationBufferMemory│
│  Step 7a: QAEvalChain (model evaluation)                    │
│  Step 7b: matplotlib + seaborn visualizations               │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│              STREAMLIT APP (Step 7c)                        │
│                                                             │
│  • KPI cards + sidebar filters                              │
│  • 8 Plotly charts (product, region, trend, heatmap…)       │
│  • Customer segmentation tab                                │
│  • Data table with search + sort                            │
│  • AI chat tab — ConversationalRetrievalChain + FAISS RAG   │
│    with memory buffer inspector                             │
└─────────────────────────────────────────────────────────────┘

RAG Flow:
  User query
    → InsightRetriever (LangChain BaseRetriever, intent-aware)
    → FAISS similarity_search (HuggingFace all-MiniLM-L6-v2 embeddings)
    → Retrieved Documents (filtered by category)
    → ChatGroq llama-3.3-70b (via LangChain)
    → ConversationBufferMemory (stores full history)
    → Answer + source categories displayed
```

## 🚀 Quick Start

### 1. Install
```bash
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # Mac/Linux
pip install -r requirements.txt
```

### 2. Add API key
```bash
cp .env.example .env
# Edit .env → paste your GROQ_API_KEY
# Free key at: https://console.groq.com
```

### 3. Run the notebook (VS Code — validate everything first)
```
Open notebooks/insightforge_analysis.ipynb
Select your venv as kernel → Run All
```

### 4. Run the Streamlit app
```bash
streamlit run app.py
# Opens at http://localhost:8501
```

## ☁️ Deploy to Streamlit Cloud

```bash
git add .
git commit -m "feat: full LangChain RAG pipeline"
git remote add origin https://github.com/YOUR_USERNAME/insightforge.git
git push -u origin master
```

1. Go to share.streamlit.io → New app → connect repo
2. Settings → Secrets → add: `GROQ_API_KEY = "gsk_..."`
3. Deploy → shareable link in ~2 minutes

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| LLM | Groq API — llama-3.3-70b-versatile |
| LLM Wrapper | LangChain ChatGroq |
| RAG Chain | LangChain RetrievalQA + ConversationalRetrievalChain |
| Vector Store | FAISS (faiss-cpu) |
| Embeddings | HuggingFace all-MiniLM-L6-v2 (free, local) |
| Memory | LangChain ConversationBufferMemory |
| Chain Prompts | LangChain LLMChain + SequentialChain + PromptTemplate |
| Evaluation | LangChain QAEvalChain |
| Retriever | Custom InsightRetriever (extends BaseRetriever) |
| UI | Streamlit |
| Charts | Plotly + matplotlib + seaborn |
| Data | pandas |
